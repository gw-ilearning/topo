## 1. 快速开始

```bash
cd D:\study\code\project3D
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。

- 开发服务器内置 Mock REST 接口，开箱即用；
- 顶栏左侧的 **3D / G6** 按钮用于切换渲染引擎；
- 页面不会定时轮询接口，切换场景或点击「刷新数据」时才会请求一次数据。

生产构建：

```bash
npm run build
npm run preview
```

- G6 页面：节点、链路、Combo 面板都绘制在 Canvas 上；

- 深浅主题切换时，画布背景、网格、节点、Combo、小地图同步换肤。

### 2.4 底部状态栏

显示当前数据源（REST / Mock）、场景名称、节点数、链路数、告警数、

## 3. 布局类型

G6 页面提供 8 种布局，点击左侧菜单即可切换：

| 布局 | 适用场景 | 特点 |
| --- | --- | --- |
| 力导向 | 通用关系图 | 节点按斥力 / 引力自然散开 |
| FA2 | 社区结构明显的图 | ForceAtlas2，聚类更紧凑 |
| 层次 | 网络层级、依赖关系 | Dagre 自上而下分层 |
| 环形 | 对等结构 | 节点均匀分布在圆环上 |
| 同心 | 核心节点居中 | 按度数从内到外排列 |
| 网格 | 机柜、设备清单 | 规整的二维网格 |
| 径向 | 以核心节点辐射 | 树状径向展开 |
| 分层 Combo | 网络分层视图 | 三层面板 + 2.5D 透视 |

切换布局时：

1. 当前布局会先停止，避免动画叠加；
2. 重新计算节点位置；
3. 渲染后做一次节点 / 层碰撞兜底；
4. 自动适配视图（可在 SDK 配置中关闭 `autoFit`）。

## 4. 分层 Combo

「分层 Combo」是 G6 页面专用的自研布局，把拓扑渲染成可拖拽的分层面板：

- **层 Combo**，按节点的 `layer` 字段从上到下堆叠；
  - 网络场景会把原始 7 个 `layer` 归并为「核心层 / 汇聚层 / 接入层」三层；
  - 其他场景仍按数据中的 `layer` 原样分层；
- 节点直接放在层上；`group` 只作为层内排布的聚类键，不生成二级分组面板；
- 每个层面板都有标题、圆角、描边与投影；
- 面板尺寸由 G6 根据子节点包围盒 + padding 自动推导；
- 布局阶段和渲染后都会做碰撞检测，正常数据下不会重叠；
- Combo 之间的碰撞用「位置 + keyShape 尺寸」的几何矩形判断，节点仍用渲染包围盒；
  这样梯形顶边外扩、阴影都不会让面板被误判重叠而平移。

### 4.1 进入分层 Combo

点击左侧菜单的「分层 Combo」。进入后菜单会额外出现两个操作：

| 按钮 | 作用 |
| --- | --- |
| 重新整理分层 | 拖动面板 / 节点后，恢复默认分层位置 |
| 2.5D 视图 | 开关梯形透视效果（默认开启） |
| 侧边角度 | 调整梯形侧边相对竖直方向的倾角（`0° ~ 30°`），左右两侧完全对称；`0°` 为矩形 |

### 4.2 拖拽

- 拖动**层面板**：整层及其子节点一起移动；
- 拖动**单个节点**：只移动该节点，适合手工微调；
  - 节点可以拖到层内任意位置：所在层的宽高会**自动扩展**，始终把节点（含标签）完整包住；
  - 扩展按帧执行，节点移动时面板会实时跟着变宽变高，不会出现节点探出面板的情况；
  - 层没有固定尺寸，因此可以把节点拖到任意方向做局部排版；
- 拖动过程中层高会随节点实时变化，但梯形左右斜边的角度（底边左右内角）始终保持不变：
  布局稳定后会冻结每层斜率，拖拽时只按 `斜率 × 当前层高` 计算收窄量；
- 松手后会立即刷新所属层的包围盒；若层之间发生重叠，会按拖动前的标准层距重新排开，整组层距保持均匀；
  - 如果把某层拖到其它层下方、改变了上下顺序，层距仍按拖动前的层距序列复用，不会因为层序变化而忽宽忽窄；
- 没有发生重叠时，拖动结束后面板不会自动回弹；
- 节点被拖到与其它节点重叠时不会自动挪位，需要时点「重新整理分层」恢复。

> 拖拽性能已做优化：拖动期间每帧最多刷新一次面板尺寸（`requestAnimationFrame`），
> 不会随 `pointermove` 高频重算，也不会隐藏连线；松手后立即拟合一次并修正层重叠，
> 修正过程临时关闭过渡动画，不会出现「等一会才推开」的情况。

## 5. 2.5D 视图（重点）

### 5.1 效果说明

开启「2.5D 视图」后，分层 Combo 会呈现「一叠悬浮梯形面板」的效果：

- **层面板变成梯形**：顶边窄、底边宽；
- **左右两侧完全对称**：底边左下 / 右下内角始终一致；
- **可自定义侧边角度**：默认所有层共用同一倾角（`trapezoidAngle`），侧边彼此平行；
- **远层更小、近层更大**：最上层约 `0.62` 倍，最下层约 `1.08` 倍；
- **斜向堆叠**：远层向右上方偏移，近层保持居中；
- **空气透视**：远层填充更淡、投影更小，近层更实、更重；
- 节点尺寸、标签字号、间距、描边、阴影会随层缩放同步变化。

2.5D 完全在二维平面内计算，不使用 CSS 3D 变换，因此：

- 命中检测、拖拽、缩放、框选、导出都正常；
- 不会出现 3D 变换导致的文字模糊或点击错位。

### 5.2 如何开关

1. 先切换到 **G6** 引擎；
2. 选择「分层 Combo」布局；
3. 点击左侧菜单中的「2.5D 视图」按钮。

按钮处于高亮状态表示已开启。再次点击即可关闭：

- Combo 回退为原生矩形；
- 所有层恢复 `1:1` 缩放；
- 斜向错位与空气透视同时消失。

开关状态保存在浏览器本地：

```
localStorage['topology-combo-depth-25d']
```

`'1'` 表示开启，`'0'` 表示关闭；默认开启。

开启后左侧菜单会出现「侧边角度」下拉框，可选 `0° / 10° / 15° / 20° / 25° / 30°`，
选择结果保存在 `localStorage['topology-combo-trapezoid-angle']`。

### 5.3 侧边角度与统一灭点

默认使用「自定义侧边角度」：所有层共用同一个 `trapezoidAngle`（侧边相对竖直方向的夹角），
左右两侧收窄量相同，因此底边左下 / 右下内角完全一致，各层侧边彼此平行。

- 可在左侧「侧边角度」下拉框调整（`0° ~ 30°`，`0°` 为矩形）；
- 布局 / `relayout()` / 修改角度后都会冻结每层斜率；拖动节点或层的整个过程中，
  层高变化只改变底边长度，底边左右内角保持不变；
- 因为左右共用同一斜率，不会再出现「同一层左右内角不一致」的问题；
- 关闭 2.5D 后不再绘制梯形，回退为矩形。

如需恢复「所有斜边汇聚到同一灭点」的一点透视模式，显式传入 `trapezoidAngle: null`。
此时灭点由当前整体布局决定：

```
灭点 X = 所有层水平包围盒的中心
灭点 Y = 最上层顶边 - 整体高度 × vanishingDistance
```

所有层的收窄量按「底边端点 → 灭点」的连线计算，所有斜边严格指向同一个点；
灭点只随布局 / 数据变化重算，拖动过程中保持不变。

```js
// 自定义侧边角度（左右对称）
await view.setLayoutOptions({ trapezoidAngle: 22 })

// 回退到统一灭点模式
await view.setLayoutOptions({ trapezoidAngle: null, vanishingDistance: 0.6 })
```

节点阵列仍按透视分布：

- 每一行节点都落在对应的透视射线上，行宽随 `y` 递增（上窄下宽）；
- 顶部行的水平间距会先按压缩比放大，透视压缩后正好回落到正常间距，既保持梯形又不互相挤压；
- `layerPadding` 的左右值（默认 `60`）略大于节点半宽，用来抵消透视压缩，
  保证顶部节点不会被层梯形的斜边切到。

### 5.4 常用参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `perspective` | `true` | 2.5D 总开关 |
| `farScale` | `0.62` | 最上层缩放比例 |
| `nearScale` | `1.08` | 最下层缩放比例 |
| `depthShiftX` | `118` | 远层向右偏移像素 |
| `depthShiftY` | `34` | 远层向上偏移像素 |
| `trapezoidAngle` | `15` | 侧边相对竖直方向的倾角（度），左右对称；`0` 为矩形，传 `null` 回退统一灭点 |
| `topInsetSlope` | `0.12` | 无灭点时的梯形斜率兜底 |
| `vanishingDistance` | `0.6` | 统一灭点模式的灭点距离系数，越大透视越弱 |
| `layerGap` | `92` | 层间固定间距 |
| `clusterGap` | `44` | 层内布局聚类间距（不渲染分组面板） |
| `nodeGap` | `30` | 节点间距 |

运行时只改参数、不切换布局：

```js
await view.setLayoutOptions({
  perspective: true,
  farScale: 0.58,
  nearScale: 1.12,
  depthShiftX: 140,
  depthShiftY: 44,
  trapezoidAngle: 20,
})
```

> 注意：切换 2.5D 必须调用 `setLayoutOptions()`。
> `setLayout()` 在 Combo 模式不变时只重新执行布局，不会重新计算节点缩放和 Combo 样式。

### 5.5 视觉验收要点

- 每个层面板呈顶窄底宽的梯形；
- 左侧与右侧内角一致，所有层共用同一侧边角度（默认侧边平行）；
- 拖动节点 / 层导致层高变化时，底边左右内角保持不变；
- 从上到下，面板与节点逐渐变大；
- 节点阵列同样上窄下宽，每一行都沿灭点射线分布；
- 节点（含标签）完整落在所属层内，不溢出斜边；
- 上层相对下层向右上方偏移；
- 关闭 2.5D 后全部恢复矩形和 1:1 缩放；
- 深浅主题下梯形填充、描边、投影都正确；
- 拖拽、悬停、右键菜单、导出 PNG 不受影响。

## 6. 主题切换

点击顶栏的太阳 / 月亮按钮即可切换深色 / 浅色主题。

- 主题选择写入 `localStorage['topology-theme']`；
- 没有历史选择时跟随系统 `prefers-color-scheme`；
- 切换时 Three.js 场景、G6 画布、面板、小地图同步更新；
- G6 画布本身保持透明，背景由页面 CSS 提供，
  因此切换主题不需要重建 Canvas，也不会残留上一套主题的背景；
- 导出 PNG 时会临时写入当前主题背景色，导出图不会透明。

## 7. 数据刷新机制

页面**不会定时轮询接口**：

- 首次进入场景时请求一次；
- 切换场景时请求一次；
- 点击顶栏「刷新数据」时请求一次；
- 接口失败或超时后自动降级到内置 Mock 数据，并在状态栏提示。

请求地址：

```
GET /api/topology?scene=network|datacenter|graph|iot
```

如果需要实时数据，可在业务层自行接入 WebSocket / SSE，
收到消息后调用 `updateGraph(data)` / `engine.updateData(data)` 做增量更新。

## 11. 常见问题

### Q1：左侧没有「2.5D 视图」按钮？

该按钮只在以下条件同时满足时显示：

1. 当前引擎是 **G6**；
2. 当前布局是 **分层 Combo**。

切换到其他布局时会自动隐藏。

### Q2：2.5D 开关点了没反应？

请确认：

- 当前处于 G6 引擎；
- 当前布局是「分层 Combo」；
- 浏览器控制台没有报错；
- 如果通过代码调用，使用的是 `setLayoutOptions()` 而不是 `setLayout()`。

### Q3：斜边角度不对 / 左右内角不一致？

默认模式使用 `trapezoidAngle` 统一侧边角度，左右两侧完全对称，不会出现左右内角不一致。
可在左侧「侧边角度」下拉框调整，或调用：

```js
await view.setLayoutOptions({ trapezoidAngle: 20 })
```

如果想恢复「所有斜边汇聚到同一灭点」的一点透视模式，传入 `trapezoidAngle: null`，
再用 `vanishingDistance` 调整灭点远近。`topInsetSlope` 只作为无灭点时的兜底。

### Q4：浅色主题下画布还是深色？

当前版本已修复：G6 画布保持透明，背景由 `.g6-host` 的 CSS 提供。
如果仍然异常，请确认没有自定义样式覆盖 `.g6-host` 的背景。

### Q5：拖拽节点时卡顿？

当前版本已针对拖拽优化：

- 拖动期间不重算 Combo 包围盒；
- 拖动期间不隐藏连线；
- 拖动期间暂停悬停卡片和小地图刷新；
- 松手后统一刷新一次面板尺寸。

如果数据量特别大（数千节点），建议关闭小地图、减少标签显示，
或使用聚合视图。

### Q6：刷新按钮为什么没有自动更新？

页面已移除定时轮询和实时推送。需要新数据时请点击「刷新数据」，
或在业务层自行接入 WebSocket / SSE。

### Q7：如何恢复默认分层？

点击左侧菜单的「重新整理分层」，或调用：

```js
await view.relayout()
```

## 12. 二次开发入口

| 文件 | 作用 |
| --- | --- |
| `src/g6/graph.js` | G6 控制器：渲染、布局、交互、事件、碰撞兜底 |
| `src/g6/layouts.js` | 布局注册中心（class 封装） |
| `src/g6/comboLayerLayout.js` | 分层 Combo 布局算法 |
| `src/g6/comboConfig.js` | 2.5D 默认参数、缩放、梯形斜率 |
| `src/g6/trapezoidCombo.js` | 自定义梯形 Combo（`BaseCombo` + `Polygon`） |
| `src/g6/theme.js` | 主题、节点 / 边 / Combo 样式 |
| `src/g6/data.js` | 业务数据 → G6 GraphData（含两级 Combo） |
| `src/sdk/topology-view.js` | 对外 SDK：`loadGraph` / `updateGraph` / `setLayoutOptions` |

最常用的运行时方法：

```js
// 切换布局
await view.setLayout('g6-combo-layer')

// 只改布局参数（例如开关 2.5D）
await view.setLayoutOptions({ perspective: false })

// 恢复默认分层
await view.relayout()

// 检查重叠
view.checkOverlaps()
```

完整 API、数据契约和样式覆盖方式见
[Topology SDK 用户指南](./topology-sdk-guide.md)。
